💡 캡컷(CapCut)에서 22px 둥근 모서리가 직각으로 보일 때 해결법
  • 직각으로 보이는 원인: 캡컷(CapCut PC/모바일)은 비디오 트랙에서 알파 투명 채널을 지원하지 않아, 둥근 모서리 바깥쪽의 투명 영역을 검은색(#000000)으로 채웁니다. 카드 본체도 어두운 색상이라 검은색 모서리와 합쳐져 직각 네모 박스로 보이게 됩니다.
  • 해결법 1 (가장 추천 · 크로마키): 위에서 [그린스크린 (MP4)]를 선택해 다운로드한 뒤, 캡컷에서 [동영상] > [오리기] > [크로마키]를 켜고 스포이드로 초록색을 1번 찍어주시면 22px 둥근 모서리가 100% 완벽하게 보존됩니다!
  • 해결법 2 (캡컷 자체 마스크): 기존 비디오를 그대로 쓰실 경우, 캡컷에서 클립 선택 후 [동영상] > [마스크] > [직사각형]을 적용하고 [모서리 둥글기]를 조절하면 캡컷 내에서 바로 둥글게 잘립니다.
  • 해결법 3 (정지 화면은 투명 PNG): 정지 화면으로 쓰실 때는 우측의 [투명 PNG 이미지 다운로드]를 누르시면 크로마키 작업 없이도 즉시 22px 둥근 모서리로 투명하게 얹어집니다.

🚀 Mac 사용자에게 배포하는 1분 방법

이 웹앱은 브라우저 캔버스에서 100% 작동하므로, Vercel(무료)에 올리면 평생 무료로 링크를 공유할 수 있습니다!

  1. 이 폴더(`shorts_tools_web`)를 GitHub 저장소에 올립니다.
  2. vercel.com에 로그인 후 [Add New Project]에서 해당 저장소를 선택합니다.
  3. [Deploy] 버튼을 누르면 1분 만에 https://내이름.vercel.app 링크가 생성됩니다.
  4. 해당 주소를 Mac 사용자에게 주면 설치 0개로 사파리나 크롬에서 즉시 사용할 수 있습니다!
