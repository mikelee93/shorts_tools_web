# 🎬 쇼츠 스튜디오 도구 (Shorts Studio Tools)
> **회전 LP 뮤직 플레이어 위젯** & **정품 유튜브 댓글 생성기** 통합 웹 애플리케이션  
> Mac / Windows / 모바일 전 기기 무설치 웹 브라우저 지원

---

## 🌟 주요 기능

### 1. 💿 360도 회전 LP 턴테이블 뮤직 플레이어 (`LP Player`)
- **실시간 60FPS Canvas 애니메이션**: 레코드판 홈(Grooves), 메탈릭 반사광, 원형 앨범 자켓이 매끄럽게 회전
- **대칭 오디오 파형 (Waveform Visualizer)**: 업로드한 음원과 실시간 동기화 또는 자연스러운 비트 시뮬레이션
- **완벽한 메타데이터 & UI 컨트롤**: 곡명, 아티스트, 발매연도, 채널 로고 배지, 재생 컨트롤러
- **원클릭 에셋 다운로드**:
  - **투명 배경 비디오 (.webm)**: 캡컷(CapCut), 프리미어 프로에서 트랙 위에 올리면 바로 투과
  - **그린스크린 비디오 (.mp4)**: 크로마키 제거용 초록색 배경
  - **투명 PNG 이미지**: 스틸컷 고화질 스냅샷

### 2. 💬 정품 유튜브 댓글 카드 생성기 (`Comment Generator`)
- **유튜브 공식 UI 100% 동일 구현**: 폰트, 여백, 좋아요 아이콘, 인증 배지 완벽 재현
- **다양한 테마 지원**: 공식 다크 모드, 라이트 모드, 글래스모피즘(반투명), 커스텀 컬러
- **유튜브 링크 자동 수집 & 프리셋**: 실시간 유튜브 링크에서 인기 댓글 추출 또는 4대 추천 프리셋(2000년대 감성, 유머, 명곡 찬양, 팩트 폭격)
- **원클릭 에셋 다운로드**:
  - **3x Retina 초고화질 투명 PNG**: 선명한 텍스트로 영상 어디든 자유롭게 배치
  - **팝업 등장 애니메이션 비디오 (.webm)**: 톡 튀어나오는 모션 그래픽 비디오

## 🚀 Mac 사용자 배포 가이드 (설치 0개 / 링크 1개로 해결)

기존에 Mac 사용자가 GitHub 소스코드를 받아 실행할 때 터미널 에러, Node/Python 버전 충돌, FFmpeg 바이너리 차단(Gatekeeper) 등으로 실패했던 문제를 **100% 웹 브라우저 렌더링** 방식으로 완벽히 해결했습니다.

### 🌐 Vercel 무료 1분 배포 (추천)
1. GitHub(github.com)에 이 `shorts_tools_web` 폴더를 저장소(Repository)로 업로드합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **[Add New Project]** 를 누릅니다.
3. 해당 저장소를 선택하고 **[Deploy]** 버튼을 클릭합니다.
4. 1분 만에 `https://프로젝트명.vercel.app` 형태의 고유 링크가 생성됩니다.
5. 이 주소를 Mac 사용자에게 공유하면 **사파리(Safari)나 크롬(Chrome)에서 링크 클릭 즉시 사용**할 수 있습니다!

## 💻 로컬 실행 방법 (Windows / 개발용)

1. `start.bat` 더블 클릭  
   *(또는 터미널에서 `node server.js` 입력)*
2. 브라우저에서 `http://localhost:4000` 접속
